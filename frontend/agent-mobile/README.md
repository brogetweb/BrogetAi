# Broget AI Agent

Android and iOS desk for agents. Sign in, keep customers, record consent, save document labels, and track loan files.

The session and the records stay on the device. The NestJS agent API is not connected yet, so nothing here is sent to a lender, a bureau, or a document store. Credit checks stay closed.

```bash
flutter run
```

Web preview:

```bash
flutter run -d web-server --web-port 8090
```
