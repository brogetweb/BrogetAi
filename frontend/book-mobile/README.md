# Book by Broget AI

Standalone Flutter booking app. UI only — no backend yet.

## Screens

1. Splash  
2. Onboarding / Get Started  
3. Home (Flights, Buses, Hotels + bottom nav)  
4. Flight search / results / detail  
5. Bus search / results  
6. Hotel search / results  
7. Review & Pay  

## Run

```bash
cd frontend/book-mobile
flutter run
```
